# PEELBEAST Image Assets

Game-ready optimized concept assets generated as separate files.

## Layout

- `generated-v1/chroma/`: 20 individual 640×640 WebP assets
- `catalog.json`: stable logical IDs and file mappings
- `PEELBEAST_IMAGE_ASSET_PACK_GITHUB_v1.zip`: downloadable archive generated by GitHub Actions

## Chroma key

All assets use a solid magenta background (`#FF00FF`) so they can be keyed or converted to alpha later. The source compositions are intentionally isolated and centered for easy replacement.

## Replacement convention

Keep the asset ID and update only the `file` mapping in `catalog.json`. Game code should reference IDs rather than hard-coded filenames.
