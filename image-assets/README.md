# PEELBEAST Image Assets

20 separate paper-craft concept assets prepared as individual chroma-key files.

## Layout

- `generated-v1/chroma/`: 20 individual 128×128 WebP preview assets
- `catalog.json`: stable logical IDs and file mappings
- `PEELBEAST_IMAGE_ASSET_PACK_GITHUB_LITE_v1.zip`: downloadable archive generated by GitHub Actions
- `SHA256SUMS.txt`: checksums for the generated asset files
- Chroma key: `#FF00FF`

The repository copy is intentionally lightweight for review and catalog integration. The high-resolution source pack is maintained separately from this preview pack.

## Replacement convention

Keep the asset ID stable and update only the catalog file mapping when production artwork changes. Game code should reference logical IDs rather than hard-coded filenames.

Large or frequently replaced objects should remain individual files instead of being merged into a single atlas. An atlas may be generated later as a build artifact, but it should not be the source of truth.
