# 전투 및 조작감 상세 설계

## 목표 감각
- 느린 턴제가 아니라 빠른 의사결정형 턴제
- 한 턴 안에 “막기 / 복구 / 공격 / 스킬”의 선택이 즉시 이해되어야 함
- 파츠 박리가 단순 디버프가 아니라 전략 자체를 바꾸게 해야 함

## 전투 1턴 흐름
1. 적 의도 확인
2. 현재 Glue / Block / 박리 상태 확인
3. 일반 행동 또는 스킬 선택
4. 즉시 결과 확인
5. 적 턴 처리
6. 다음 턴 재정비

## 조작감 보강 예정
- 액션 버튼 프레스 애니메이션
- 히트스탑
- 숫자 팝업
- 박리 시 파편/찢김 이펙트
- 상태 아이콘 고정 바

## 밸런싱 포인트
- 기본 전투 4~6턴 길이 목표
- 엘리트 6~9턴
- 보스 10~14턴
- 지나친 회복 루프나 무한 Glue 루프 제한 필요
