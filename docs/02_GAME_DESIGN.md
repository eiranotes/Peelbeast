# 02 — 게임 디자인

## 1. 핵심 명제

> HP가 깎이는 것과 **빌드가 무너지는 것**이 동시에 긴장 요소인 턴제 로그라이크.

다른 덱빌더에서 잃는 것은 자원과 체력이다. PEELBEAST에서 잃는 것은 **몸의 일부**다.
가위가 벗겨지면 공격력이 떨어지는 것으로 끝나지 않는다. Scissor Flurry가 잠기고,
Sharp Snip 패시브가 꺼지고, Cutting Crew 시너지가 깨지고, 화면 속 캐릭터의 손에서
가위가 사라져 책상 위에 떨어져 있다.

## 2. 플레이 루프

```
        ┌──────────────────────────────────────────┐
        │                                          │
   Title → Route Select → Workshop → Node → Reward ┘
                             ↑         │
                             └─────────┘
                          (Event / Shop / Combat)
                                       │
                                    Result
```

한 런은 노드 7개, 15~25분을 목표로 한다.
매 노드 사이에 작업대로 돌아오므로 **다음 적을 보고 빌드를 고치는** 것이 기본 리듬이다.

## 3. 파츠

슬롯 4개 × 3종 = 12파츠. 각 파츠는 다음을 **전부** 바꾼다:

1. 화면 위 이미지 레이어 (`04_ASSEMBLY_AND_PEEL_SYSTEM.md` §2)
2. 스탯 (HP / Glue / ATK / SPD / 박리저항)
3. 액티브 스킬 1개 (쿨다운과 Glue 비용을 가진다)
4. 패시브 1개 (전투 규칙에 실제로 참여한다)
5. 시너지 참여 자격
6. 전투 애니메이션

| 슬롯 | 파츠 | 성격 |
|---|---|---|
| Head | Toast Helm | Focus를 쌓아 기본 공격을 밀어 올린다 |
| | Box Shell | 느리지만 단단하고 잘 벗겨지지 않는다 |
| | Ghost Hood | Drift로 피해를 흘리고 속도를 얻는다 |
| Hand | Scissors | 고정된 상대를 크게 벤다 |
| | Pencil Spear | 관통하고 Pinned를 남겨 연계를 만든다 |
| | Umbrella Hook | 잉크와 속박에 강하다 |
| Core | Bomb Belly | Glue를 태워 큰 화력을 낸다 |
| | Coffee Cup | Glue와 템포를 유지한다 |
| | Tape Roll | 벗겨진 파츠를 되붙인다 |
| Trinket | Ribbon Knot | 속도와 회피 |
| | Eye Sticker | 적 의도의 정확한 수치를 공개한다 |
| | Bread Patch | 몸과 파츠를 함께 꿰맨다 |

각 슬롯은 **비워둘 수도 있다.** 빈 슬롯은 벗겨질 것이 없다는 뜻이기도 하다.

## 4. 시너지

두 파츠가 **동시에 장착되어 있고 둘 다 벗겨지지 않은 동안에만** 활성화된다.
한쪽이 벗겨지면 즉시 깨지고, 작업대와 전투 UI 모두 "깨짐"으로 표시한다.

| 시너지 | 요구 | 효과 |
|---|---|---|
| Warm Breakfast | Toast Helm + Coffee Cup | 모든 스킬의 쿨다운이 1 짧아진다, 최대 Glue +2 |
| Precision Draft | Pencil Spear + Eye Sticker | Pinned 상대에게 기본 공격 +3 |
| Weatherproof | Umbrella Hook + Tape Roll | 잉크 피해 -2, 박리저항 +2 |
| Reinforced Package | Box Shell + Bread Patch | Guard 시 벗겨진 파츠 1개 자동 복구, HP +3 |
| Cutting Crew | Scissors + Bomb Belly | ATK +2, 기본 공격이 Fragile 부여 |
| Ghost Ribbon | Ghost Hood + Ribbon Knot | SPD +3, 첫 피격 완화 +2 |

시너지는 순수 데이터다. `src/game/data/synergies.ts`에 한 항목을 추가하면 끝이고,
리졸버는 건드리지 않는다.

## 5. 런 구조

### 5.1 노드 타입

| 타입 | 역할 | Scrap |
|---|---|---|
| Combat | 일반 전투 | 9~10 |
| Elite | 압박이 강한 전투 | 14 |
| Boss | 2페이즈 | 20 |
| Event | 선택지 3~4개, 즉시 런에 반영 | — |
| Shop | 파츠 / 리릭 / 서비스 구매 | — |

### 5.2 루트

두 루트는 순서만 다른 것이 아니라 **성격이 다르다.**

| | Snip Lane | Stitch Loop |
|---|---|---|
| 위험도 | 낮음 | 높음 |
| Scrap | 보통 | 많음 |
| 회복 기회 | 넉넉 | 희박 |
| 상점 위치 | 중반 (4번째) | 후반 (5번째) |
| 엘리트 | 없음 | 3번째 |
| 성격 | 박리 압박이 낮아 파츠 의존 빌드에 유리 | Ink와 박리가 일찍 몰아쳐 Tape Roll·Umbrella·Bread Patch 계열이 크게 유리 |

이 프로필은 루트 선택 화면에 그대로 표시된다. 선택이 "느낌"이 아니라 정보에 근거하도록 하기 위해서다.

### 5.3 캐리오버

전투가 끝나면 남은 HP/Glue가 다음 노드로 이어지고, 승리 시 최대치에 비례해 회복된다
(HP +4 및 최대 HP의 34 %, Glue +6 및 최대 Glue의 50 % — §8.3 참조).
작업대에서 최대치가 낮은 빌드로 바꾸면 이월값도 함께 클램프된다 —
"HP 최대치를 늘리는 파츠를 전투 직전에만 끼우는" 회피를 막기 위한 규칙이며,
`tests/unit/run.test.ts`가 이를 검증한다.

## 6. 자원

| 자원 | 역할 |
|---|---|
| HP | 0이 되면 런 종료 |
| Glue | 스킬 비용. **0이면 턴 시작 시 파츠가 하나 벗겨진다** |
| Block | 피해를 흡수하고, 임계값 이상이면 박리 시도 자체를 막는다 |
| Scrap | 노드 간 화폐 |
| Ink Tide | 전투 전역 게이지. 5 이상이면 매 라운드 추가 피해 |

Glue가 단순 마나가 아니라 **접착제**라는 점이 이 게임의 자원 설계다.
스킬을 쓰면 몸이 헐거워진다.

## 8. 밸런싱

### 8.1 목표

- 일반 전투 4~6턴 · 엘리트 6~9턴 · 보스 10~14턴 · 한 런 15~25분

### 8.2 측정

결정론 덕분에 배치 시뮬레이션이 가능하다.

```bash
npm run simulate -- --runs 40 --encounters
```

9개 대표 빌드 × 2루트를 각각 N회 자동 플레이하고 승률·전투 길이·박리 횟수·사망 지점을 낸다.
정책은 "유능하지만 최적은 아닌" 플레이어이므로 **절대 승률은 비관적**이다.
읽어야 할 신호는 빌드 간·루트 간 **격차**다.

### 8.3 1차 패스 결과 (40 runs/cell)

첫 측정에서 **18개 조합 전부 승률 0 %** 였다. 원인 세 가지를 찾아 고쳤다:

| 문제 | 조치 |
|---|---|
| Fury가 상한도 감쇠도 없이 **매 타격마다** 더해져, 긴 전투가 필승 불가 나선이 됐다 | 상한 2, 그리고 **의도당 1회**만 적용 |
| 7노드 누적 피해를 회복할 수단이 없었다 (승리 시 +4 고정) | 승리 시 최대 HP의 34 % + 4 회복 |
| 보스 2페이즈가 소진된 빌드를 상대로 열렸다 | 페이즈 전환 시 플레이어도 최대 HP의 25 % 회복 |

여기에 적 HP 하향(rat 30→24, spider 38→28, crow 44→34, boss 36+42→24+28),
기본 ATK 3→4, Repair 3→5, 최상위 의도 피해 하향을 더했다.

결과:

| | 이전 | 이후 |
|---|---|---|
| 승률 범위 | 0 – 0 % | 0 – 62.5 % |
| 보스 클리어 | 0 % | 42 % |
| 엘리트 클리어 | 4 % | 60 % |
| 거미 클리어 | 38 % | 93 % |

### 8.4 남은 밸런스 과제

- **전투가 여전히 길다.** 측정 평균 11~16턴, 목표는 4~9턴.
  적 HP를 더 줄이거나 플레이어 화력을 올려야 한다
- **`box/umbrella/tape/patch`는 승률 0 %, 전투 61턴.**
  네 파츠 모두 공격 기여가 거의 없어 승리 조건이 없는 함정 빌드다.
  방어 빌드에 화력 전환 수단(예: Block을 피해로 바꾸는 파츠)이 필요하다
- `moth`가 100 % 클리어로 너무 쉽다
